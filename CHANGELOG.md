# Changelog

All notable user-facing changes should be recorded here before a release.

This project follows a lightweight changelog during the `0.x` public-alpha
period. Keep entries concrete and separate stable API changes from experimental
research or experiment-workflow changes.

## 0.1.0 — 2026-08-02

- Stabilized the public core boundary around square-cell simulation, fixed
  static terrain, flat terrain friction, rendering, and parity validation.
- Marked slope terrain as unsupported experimental geometry with slope
  friction/support disabled.
- Added CI, package-boundary checks, and community process files for the public
  alpha release.
