# Code of Conduct

This project is intended to be a usable research library and a constructive
space for simulator, robotics, and machine-learning contributors.

## Expectations

- Treat contributors respectfully and assume technical discussions are about the
  work, not the person.
- Keep criticism specific, evidence-based, and actionable.
- Be clear about uncertainty, especially for physics, math, and benchmark claims.
- Respect the stable API boundary and label experimental work honestly.

## Unacceptable Behavior

- Harassment, threats, or discriminatory language.
- Personal attacks or repeated hostile conduct.
- Publishing private communication or personal information without consent.
- Presenting unsupported results as validated public-library behavior.

## Reporting

Report conduct concerns privately to the maintainer through GitHub at
[@btgaskin](https://github.com/btgaskin). Maintainers may remove content, close
threads, restrict participation, or take other proportionate action to keep the
project usable for contributors.
